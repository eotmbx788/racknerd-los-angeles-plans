## “洛杉矶”这个标签，你实际买到的是什么

买洛杉矶买的是位置。洛杉矶是跨太平洋海缆在美本土的主要登陆点，这让它同时承担两个角色：服务美国西海岸本地用户，以及作为美国到亚太延迟最低的桥接点。

| 目的地 | 典型 RTT |

这组数字来自商家的自报平均值，走公网路由，实际会随运营商、路径和时段波动。东京一项不同商家的口径有出入，一家记 108ms，一家记约 100ms，所以写成区间更准确。

对国内读者更有参考价值的是另一组数据：第三方测评机构测过洛杉矶走三网直连 BGP 的机器，国内 Ping 平均约 167ms，并指出普通美国机房普遍在 200ms 以上。这是单一来源的转述，你的城市和运营商不同，结果会有差异，下单前用商家提供的测试 IP 自己 Ping 一遍最稳。

如果你主要服务的是亚洲用户，洛杉矶只是"离得比较近"，真要低延迟，东京或新加坡机房才是答案。

## 回国线路分三档，别为用不上的优化掏钱

## 常见问题

**年付还是月付？**

RackNerd 的 KVM 线是年付制，Windows 线是月付制，两条线不通用。年付适合已经确定要用满一年的场景，月付适合还在试探的阶段。第一次用新商家、又不确定线路表现，先买最小档年付验证，损失可控。

**续费会不会涨价？**

参照抽奖活动的续费口径，4GB 档第二年按 $59.99/年，与标价一致。年付用户按当期标价续费即可，不存在首年低价、次年翻倍的定价结构。

**国内访问延迟大概多少？**

洛杉矶走普通国际线路的机器，国内 Ping 通常在 200ms 上下；走三网直连 BGP 的能压到 167ms 左右。这是第三方测评的转述数据，你的实际结果取决于所在城市、运营商和时段。下单前用测试 IP 自己测。

**怎么确认拿到的是原生 IP？**

看 IP 注册地和流媒体解锁表现，用 whois 查归属，再实际打开目标服务验证。广播 IP 在某些场景下会出问题，做跨境电商和流媒体相关业务尤其要提前确认。

**能不能装 Windows？**

KVM 年付档给的是 Linux 和 Root 权限，装 Windows 需要自行解决授权。要正规 Windows 环境和远程桌面，直接买 Windows VPS 线。
